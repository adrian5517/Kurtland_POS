Place the provided Kurtland logo image here to enable the sidebar logo and site icon (favicon).

Required path names used by the app:
- kurtland_logo.png      -> sidebar logo (used responsively in the dashboard)
- kurtland_logo.png      -> sidebar logo (used responsively in the dashboard) and recommended as tab icon
- favicon.ico            -> optional legacy favicon (place an ICO file here if available)

Optional (recommended) favicon files:
- icon-light-32x32.png   -> 32x32 PNG for light mode
- icon-dark-32x32.png    -> 32x32 PNG for dark mode
- icon.svg               -> vector icon
- apple-icon.png         -> iOS touch icon
- favicon.ico            -> legacy favicon

How to add:
1. Save your uploaded logo image to `public/kurtland_logo.png`.
2. (Optional) Create a `public/favicon.ico` (multi-size ICO) from the logo for maximum browser compatibility.
2. (Optional) Use an image tool to export 32x32 PNGs and `favicon.ico` and put them in `public/`.

After adding images, restart the dev server if necessary:

```bash
pnpm dev
# or
npm run dev
```
