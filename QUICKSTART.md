### Step 3: Explore the Features

#### 🛒 POS Dashboard
- Search for products by name or code
- Click "Add" to add items to cart
- Adjust quantities with +/- buttons
- Select payment method (Cash, Card, Transfer)
- Enter paid amount
- Click "Checkout" to complete sale

#### 📦 Inventory Management
- Go to **Inventory** in sidebar
- Click **Add Product** to create new items
- Edit existing products
- Track stock levels
- Set pricing and cost

#### 📊 Sales Reports
- View **Reports** dashboard
- See total revenue and transaction stats
- Top selling products
- Performance metrics
- 30-day analytics

#### 👥 User Management
- Add/edit team members
- Assign roles (Admin, Manager, Cashier)
- Activate/deactivate users
- Track team activity

#### ⚙️ Settings
- Update business information
- Change password
- Configure security settings
- Monitor system status

## 🆘 Common Tasks

### Add a New Product
1. Go to **Inventory**
2. Click **Add Product**
3. Fill in: Code, Name, Price, Category
4. Click **Create Product**

### Process a Sale
1. Use search or scroll to find products
2. Click **Add** for each item
3. Adjust quantities in cart
4. Select payment method
5. Enter amount paid
6. Click **Checkout**

### View Sales Report
1. Go to **Reports**
2. See top products and revenue
3. Review performance metrics
4. Check trends and peak hours

### Create New User
1. Go to **Users**
2. Click **Add User**
3. Enter email and name
4. Select role
5. Click **Create User**

### Change Password
1. Go to **Settings**
2. Find "Change Password" section
3. Enter current and new passwords
4. Click **Update Password**

## 🔧 Troubleshooting

### Page Won't Load
- Check internet connection
- Clear browser cache (Ctrl+Shift+Delete)
- Reload page (Ctrl+R)
- Try different browser

### Logout Issues
- Click Logout button in sidebar
- If stuck, clear cookies and reload
- Check browser console for errors

### Data Not Showing
- Verify you have required permissions
- Check if items are in active status
- Try refreshing the page
- Contact admin for data access

### Performance Issues
- Reduce search results (use more specific terms)
- Clear browser cache
- Close other tabs
- Use Chrome/Firefox for best performance
